# File name and destination guide

`configuration/applications/kitty/kittyScheme.conf` : `~/.config/kitty/kitty.conf`
`configuration/applications/micro/microScheme.micro` : `~/.config/micro/colorschemes/micro.micro`
`configuration/applications/rofi/rofiScheme.rasi` : `/usr/share/rofi/themes/rofi.rasi`
`configuration/desktop/firefoxBookmarks.html` : No copy destination configured in the setup scripts
`configuration/desktop/vsCodeKeybindings.json` : No copy destination configured in the setup scripts
`configuration/desktop/xfce4Desktop.xml` : `~/.config/xfce4/xfconf/xfce-perchannel-xml/Xfce4-desktop.xml`
`configuration/desktop/xfce4KeyboardShortcuts.xml` : `~/.config/xfce4/xfconf/xfce-perchannel-xml/Xfce4-eyboard-shortcuts.xml`
`configuration/desktop/xfce4PowerManager.xml` : `~/.config/xfce4/xfconf/xfce-perchannel-xml/Xfce4-power-manager.xml`
`configuration/desktop/xfce4Settings.xml` : `~/.config/xfce4/xfconf/xfce-perchannel-xml/Xfce4Settings`
`configuration/desktop/thunar.xml` : `~/.config/xfce4/xfconf/xfce-perchannel-xml/Thunar.xml`
`configuration/fonts/jetbrainsMonoFont.zip` : Extracted to `/usr/share/fonts/truetype/jetbrains-mono`; archive contents keep their names
`configuration/fonts/protoNerdFont.zip` : Extracted to `/usr/share/fonts/truetype/proto-nerd`; archive contents keep their names
`configuration/icons/papirusMaceDarkIcon.tar.gz` : Extracted to `~/.icons`; archive contents keep their names
`configuration/themes/whitesurTheme.tar.xz` : Extracted to `~/.themes`; archive contents keep their names
